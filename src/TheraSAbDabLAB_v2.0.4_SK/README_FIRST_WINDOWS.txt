THERA-SABDAB WHO INN CURATOR v1.0.4 - WINDOWS

1. Extract the complete ZIP to a normal folder.
2. Double-click START_APP.bat.
3. This release uses the Python already installed on your Windows PC.
4. It creates a private environment at %LOCALAPPDATA%\TSCurator\venv104.
5. Your system Python packages are not modified.
6. On first run, pip downloads the pinned free dependencies into that private environment.
7. If setup was interrupted, run REPAIR_AND_RUN.bat.
8. DIAGNOSE_WINDOWS.bat writes %LOCALAPPDATA%\TSCurator\logs\diagnostic_report_v104.txt.

BUILD_STANDALONE_EXE.bat is optional. START_APP.bat is sufficient to use the application.
